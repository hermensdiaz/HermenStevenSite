# Propósito de usar el sitio web de hermensteven

- Divertirme al trabajar diario en el sitio.
- Mejorar mis habilidades con git y ser activo.
- Mejorar mis habilidades con JS.
- Evitar usar IA para el código pues necesito practicar JS.
- Desarrollar mini juegos y apps curiosas.
- Dejar volar mi imaginación.
- Puedo practicar el proceso de desarrollo completo del software, es decir: requisitos, diseño, construcción, verificación y validación, y mantenimiento. Ej.: Crear un videojuego 2d de un alien que aterriza en una luna y tiene que encontrar piezas para que su nave pueda volver a su planeta, tiene que luchar con enemigos lunares, esquivar obstáculos y reunir todas las piezas, ahora armar sus requisitos, su diseño, lo construyo, hago la verificación y validación, y le doy mantenimiento.
- Es para mí, por ahora no pienso que las personas entrarán al sitio.
- Actualizar los documentos conforme vallan surgiendo ideas.
